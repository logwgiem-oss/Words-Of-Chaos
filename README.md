# Words of Chaos

A multiplayer party game where players compete through ridiculous prompts,
funny answers and creative challenges.

## Game modes

- Caption Chaos
- Fill the Gap
- Worst Answer
- Fake It
- Picture Perfect
- Drawing Telephone
- Who Said That?

## Built with

- React
- Vite
- Supabase
- CSS

## Installation

Install Node.js, then open a terminal in this folder.

Run:

npm install

Create a `.env` file using `.env.example` as a guide.

Add your Supabase project URL and publishable key.

Run:

npm run dev

## Build

npm run build

The production website files will be created in the `dist` folder.

## Important

This is an early prototype. Some game modes and multiplayer
features still need completing before public release.
